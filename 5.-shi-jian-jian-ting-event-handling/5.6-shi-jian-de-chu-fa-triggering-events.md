# 5.5 觸發事件與解除事件綁定

## .trigger()：觸發事件

一個按鈕點擊，觸發其它元素的事件：

```javascript
$("#btn2").trigger("click");
```

也可以這樣寫(較常見)：

```javascript
$("#btn2").click();
```
