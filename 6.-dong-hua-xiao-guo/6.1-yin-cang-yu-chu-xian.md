# 6.1 基本效果

## .hide() 與 .show()



分別觀察以下程式：

```javascript
$("div.div_block").hide();
```

```javascript
$("div.div_block").hide(10000);
```

```javascript
$("div.div_block").hide(10000).show(10000);
```

```javascript
$("div.div_block").toggle(10000);
```

代入完成動畫效果之後所要執行的函式參數，例：

```javascript
$("div.div_block").hide(function(){
  alert("跑完效果，自訂其它程式");
});

$("div.div_block").hide(10000, function(){
  alert("跑完效果，自訂其它程式");
});
```
