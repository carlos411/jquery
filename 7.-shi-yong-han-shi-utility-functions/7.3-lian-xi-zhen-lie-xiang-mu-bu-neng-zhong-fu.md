# 7.2 練習：陣列項目不能重覆

提供一個陣列：

```javascript
let line_ids = ["a", "b", "c", "a", "y", "c"];
```

撰寫 jQuery 語法，執行迴圈，將重覆的 line\_id 移除。

印出結果如下：

```javascript
["a","b","c","y"]
```
