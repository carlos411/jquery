# 7.1 陣列(Array)相關

## $.inArray() 判斷是否有該值

說明：有的話，回傳該值的**索引值**；沒有的話，回傳 **`-1`**。

語法：

```javascript
let items = [1, 2, 3];
  
alert( $.inArray(1, items) ); // 回傳 1 的索引值：0
alert( $.inArray(3, items) ); // 回傳 3 的索引值：2
alert( $.inArray(4, items) ); // 回傳 4 的索引值，因為找不到，故回傳 -1
```

## $.merge() 陣列的合併

說明：將第二個陣列合併到第一個陣列。

例：

```javascript
let items = [1, 2, 3];
let items2 = [2, 3, 4];
  
$.merge(items, items2);
  
console.log(items);  // [1, 2, 3, 2, 3, 4]
console.log(items2); // [2, 3, 4]
```

## $.each() 跑迴圈

說明：將陣列依序跑迴圈。

語法一：

```javascript
let items = [1, 2, 3, 4]; // 陣列

$.each(items, function(index, item){
  console.log("索引值：" + index + "； 值：" + item)
});

/* 印出如下：
索引值：0； 值：1
索引值：1； 值：2
索引值：2； 值：3
索引值：3； 值：4
*/
```

語法二：直接用在選擇子所選到的元素陣列

```javascript
$("p").each(function(index, item){
  console.log("索引值：" + index + "； 內容：" + $(item).text());
});

/* 印出如下：
索引值：0； 內容：段落一
索引值：1； 內容：段落二
*/
```
